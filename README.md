# Kanva

An intermediate scene representation for vector graphics.

## Overview

Kanva is a Rust library that provides an intermediate representation for vector graphics, making it easier to work with and manipulate vector-based scenes.

## Features

- Intermediate scene representation
- Vector graphics support
- Built with Rust for performance and safety

## Installation

Add this to your `Cargo.toml`:

```toml
[dependencies]
kanva = "0.1.0"
```
